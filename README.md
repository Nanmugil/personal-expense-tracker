# Personal Expense Tracker

A Python command-line application for recording,
viewing, filtering, and summarizing daily expenses.

## Features
- Add expenses with date, category, amount, and description
- View all saved expenses
- Filter expenses by category
- Calculate category-wise spending totals
- Store records persistently using CSV file handling
- Validate user input and handle errors

## Technologies Used
- Python 3
- CSV module
- File handling
- Dictionaries and lists
- Exception handling

## Project Structure
```text
PersonalExpenseTracker/
├── expense_tracker.py

```

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run `python expense_tracker.py`.

The program creates `expenses.csv` automatically
to store expense records.

## Learning Outcomes
Practiced Python functions, loops, dictionaries,
CSV read/write operations, and input validation.
